# Sunithaenterprises-v2

Architectural German uPVC Window Systems website for Sunitha Enterprises.

## Overview
- **Exclusively uPVC Windows**: Sliding, Casement, Villa (with SS 304 Mesh & Safety Grill), Tilt & Turn, Arch & Curved, Combination Facades.
- **3D Spatial Scrollytelling Engine**: 300-frame interactive 360° studio rotating viewer.
- **Quiet Luxury Design**: Editorial layout with Cormorant Garamond & Plus Jakarta Sans typography.
- **Mobile Optimized**: Full-screen navigation drawer, touch controls, and sticky action bar.

## Tech Stack
- HTML5 / CSS3 / Modern JavaScript (ES Modules)
- Vite Bundler & Dev Server
- Web Audio API Sound Synthesizer
